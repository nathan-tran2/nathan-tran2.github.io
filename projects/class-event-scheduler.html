Overview

A scheduler covering both academic classes and user-defined events, written across Java, C and React.

How it works

  • Inheritance and polymorphism keep class behaviour and custom-event behaviour distinct while sharing a common base.
  • Search filters narrow a full course catalog.
  • Timers and flags drive reminders.
  • Built with a team on Agile sprints, with structured conflict resolution, GitHub for version control and JUnit tests for each module.
