Overview

An ATM login flow that replaces the PIN with real-time facial recognition, then handles the account itself from a command line.

How it works

  • Haar Cascades detect the face and LBPH identifies it, trained on labeled image sets and robust to changes in lighting and expression.
  • After sign-in, the account data is read and written in SQLite, with a CLI for balance checks, withdrawals and transaction logging.
  • Authentication, interface and database sit in separate layers, so each can be tested on its own.
  • Failed detection, database errors and unauthorized access are handled as expected states rather than crashes.
